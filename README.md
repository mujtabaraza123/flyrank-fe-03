# Intern Task 3 — React + TypeScript + Vite starter

This repository is a minimal, clean starting point for a React application using TypeScript and Vite.

Project structure
- index.html — Vite entry
- src/
  - main.tsx — app entry
  - App.tsx — main component
  - index.css — global styles
- tsconfig.json — TypeScript configuration
- vite.config.ts — Vite configuration
- package.json — scripts and dependencies

Scripts
- npm run dev — start development server (Vite)
- npm run build — produce a production build
- npm run preview — preview the production build locally
- npm run typecheck — run TypeScript type checking (no emit)

Notes
- This is intentionally minimal: no movie features, Firebase, or external API integration yet.
- Keep the project structure simple and add features as separate modules in src/ when ready.
